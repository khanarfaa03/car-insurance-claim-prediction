# 🚗 Car Insurance Claim Prediction

Predictive classification model designed to forecast customer auto insurance claims for **On the Road** car insurance company. This project identifies key risk factors and evaluates baseline machine learning models to maximize claim prediction accuracy.

---

## 📌 Project Overview

Insurance providers require accurate risk modeling to optimize pricing strategies and anticipate policy claims. This project analyzes customer demographic, behavioral, and vehicle data (`car_insurance.csv`) to build an interpretable, baseline classification pipeline optimized for prediction accuracy.

Key Goals:
* Identify top feature predictors for auto insurance claims.
* Build and evaluate machine learning models for baseline deployment.
* Deliver actionable risk assessment insights for insurance pricing strategies.

---

## 🛠️ Data & Tech Stack

* **Language:** Python
* **Libraries:** `pandas`, `numpy`, `scikit-learn`, `matplotlib`, `seaborn`
* **Dataset:** `car_insurance.csv` (Customer demographic, driving history, and vehicle attributes)
